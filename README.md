# Eden Touch 使用指南

Eden Touch 是基于 [Eden](https://git.eden-emu.dev/eden-emu/eden) 的 Android 触控增强版本。它解决的核心问题是：

> 让没有实体手柄、或只想用触屏玩 Switch 游戏的用户，能够像使用手柄一样操作游戏，并且可以针对不同游戏、不同场景保存自己的触控布局。

下载地址：<https://github.com/PluvIIter/eden-android-touch/releases>

> Eden Touch 是非官方分支，与 Eden 官方无直接关系。

## 1. 它能做什么

Eden Touch 不是简单地把手柄按键画到屏幕上，而是提供一套完整的触控输入系统：

- 用触屏模拟手柄按键、摇杆和组合键；
- 为不同游戏保存不同布局；
- 用划屏区域控制视角；
- 用手势完成复杂操作；
- 用外观按钮快速切换颜色、透明度和隐藏状态；
- 用切换模板按钮在“战斗布局”和“菜单布局”等场景之间切换；
- 针对不同屏幕尺寸保存不同控件位置；
- 导入导出布局，方便备份和分享。

## 2. 两种安装包

| 版本 | 包名 | 应用名称 | 适合谁 |
|---|---|---|---|
| 普通版 | `dev.eden.eden_emulator.touch` | Eden Touch | 大多数用户 |
| Genshin Spoof 版 | `com.miHoYo.Yuanshen` | Eden-TouchG | 需要该包名兼容性的设备 |

Eden-TouchG 使用《原神》国服包名，目的是继承部分厂商针对该包名的优化。它不会运行《原神》，也不能和真正的国服《原神》同时安装。没有特殊需求时，优先使用普通版。

## 3. 五分钟上手

### 第一步：准备布局

打开 Eden Touch，添加游戏后进入“触控模板”。

- 第一次使用：复制默认布局，改起来更快；
- 想从零开始：新建空白布局。

### 第二步：添加常用控件

进入布局编辑器，点击“添加”。

一个典型的动作游戏布局可以先放：

- 一个左摇杆：控制移动；
- 一个右侧划屏区域：控制视角；
- 四个普通按钮：A/B/X/Y；
- 两个肩键按钮：L/R 或 ZL/ZR。

### 第三步：设置映射

选中控件，在“输入”中设置手柄映射。

- 普通按钮可以只映射一个键，也可以映射组合键；
- 摇杆选择左/右目标；
- 划屏区域选择目标摇杆和划屏参数；
- 手势区域为每个方向设置按键和/或摇杆方向。

### 第四步：调整位置和大小

- 单击画布放置：沿用上一次同类型控件的大小和形状；
- 拖动放置：拉出新的尺寸；
- 选中后拖动移动，拖边角缩放。

### 第五步：保存并测试

保存布局，回到游戏测试。也可以在编辑器中先用测试模式确认摇杆方向、按键和手势是否正常。

## 4. 布局模板的作用

一个布局模板就是一套完整的触控方案。它包含：

- 控件；
- 每个控件的位置和大小；
- 不同屏幕尺寸的放置；
- 颜色、透明度等外观设置；
- 使用的划屏参数和外观参数。

### 为什么需要多个布局

不同游戏需要不同操作，例如：

- 动作游戏需要摇杆、视角划屏和多个技能键；
- 格斗游戏更依赖 ABXY 组合键和手势；
- 赛车游戏可能只需要少量按钮和方向控制；
- 游戏菜单和战斗场景可以使用不同的按钮布局。

### 屏幕配置

同一个布局可以为不同屏幕尺寸保存不同位置。

例如手机横屏和折叠屏展开后的比例不同，控件可以分别调整，避免在大屏上挤在一起或在小屏上超出边界。

## 5. 控件怎么选

### 5.1 普通按钮：最常用的操作键

**作用**

触发一个手柄按键，或一组手柄按键。

**适合场景**

- 攻击、跳跃、确认、取消；
- 技能键、肩键、扳机键；
- 需要长按的按键；
- 需要连续触发的按键。

**可以怎么用**

- 单键映射：一个按钮对应一个手柄键。
- 组合映射：一个按钮同时按下多个手柄键，适合组合技能。
- Turbo：按住按钮时反复触发，适合连发场景。
- 触觉反馈：按下时提供振动反馈。

**例子**

在动作游戏里：

- A 按钮映射 A；
- B 按钮映射 B；
- 一个“闪避”按钮映射 ZL + B；
- 一个“连发”按钮开启 Turbo，映射 X。

### 5.2 组合按键：把 ABXY 或方向键做成一个整体

**作用**

把四个相关按键放在一个控件里，减少布局占用，并保留独立按键输入。

**适合场景**

- 格斗游戏；
- 需要频繁使用 ABXY 的动作游戏；
- 需要方向键组合的游戏；
- 想保留手柄布局直觉的用户。

**两种样式**

- ABXY 菱形组合：适合动作、格斗、角色扮演；
- 方向键组合：适合菜单、格斗、需要方向输入的场景。

每个子键仍然可以独立映射。

### 5.3 摇杆：移动、转向和力度控制

**作用**

模拟左摇杆或右摇杆，并把触屏位置转换成方向和力度。

**适合场景**

- 角色移动；
- 赛车转向；
- 相机旋转；
- 需要轻推/重推区分的操作。

**可见摇杆**

屏幕上显示一个圆形摇杆，适合需要明确操作位置的用户。

**隐藏摇杆**

只保留触摸区域，不显示圆形摇杆。适合：

- 已经熟悉固定操作位置；
- 不想遮挡游戏画面；
- 希望触控区域更大。

**自由摇杆**

手指超出半径时，摇杆中心跟随手指移动。适合需要大幅度拖动的操作。

**辅助按键**

推动摇杆时可以同时触发一个额外按键，适合“移动 + 攻击”的组合操作。

**双击辅助**

短时间再次按下摇杆时触发强化行为，适合冲刺、闪避等操作。

### 5.4 划屏区域：控制视角和相机

**作用**

把手指滑动转换成摇杆方向，常用于相机和视角。

**适合场景**

- 3D 动作游戏转视角；
- 射击游戏瞄准；
- 赛车游戏观察周围；
- 需要比固定摇杆更自然的滑动操作。

**和摇杆的区别**

- 摇杆更像“推动一个固定方向”；
- 划屏更像“拖动画面转动视角”。

**划屏参数**

划屏区域可以引用一个独立的划屏参数模板，用来调整：

- 水平/垂直灵敏度；
- 响应曲线；
- 目标摇杆。

多个区域可以共用同一套划屏参数，修改一次即可同步生效。

### 5.5 手势区域：复杂操作的快捷入口

**作用**

识别滑动方向或点击，并触发对应的按键或摇杆输入。

**适合场景**

- 一键释放组合技；
- 滑动触发技能；
- 点击区域触发菜单或特殊动作；
- 需要比普通按钮更复杂的输入。

**支持的操作**

- 上、下、左、右；
- 四个斜方向；
- 单击；
- 设置触发距离；
- 每个方向可同时绑定按键和摇杆方向；
- 达到距离立即触发，或抬手时触发；
- 手势保持：达到阈值后持续按住映射键，直到松手；
- 脉冲：触发后自动释放。

**例子**

- 向上滑：触发“上 + 攻击”；
- 向右滑：触发闪避；
- 单击：触发交互键；
- 长按滑动：保持技能蓄力。

### 5.6 显隐按钮已经取消

旧版的“显示/隐藏”按钮本质上是把控件透明度变成 0。现在请使用外观参数实现。

**隐藏全部控件的做法**

1. 在“外观参数”页新建一个外观模板；
2. 添加一个叠加透明度为 0% 的外观组；
3. 给外观按钮选择这个模板；
4. 按外观按钮在“原始组”和“隐藏组”之间切换。

旧布局里的显隐控件会变成停用的普通按钮，不再执行显隐。

## 6. 特殊按钮：外观和切换模板

### 6.1 外观按钮：快速切换显示风格

**作用**

循环切换一个外观参数模板中的外观组，改变控件颜色和叠加透明度。

**适合场景**

- 游戏画面太亮时降低控件亮度；
- 游戏画面太暗时提高控件亮度；
- 隐藏控件，只看游戏画面；
- 切换不同主题颜色；
- 为不同场景准备不同外观。

**使用方式**

1. 在“外观参数”页新建外观模板；
2. 编辑外观组；
3. 在普通按钮的动作中选择“外观”；
4. 选择外观模板。

**多个外观按钮可以共享同一个外观模板**

例如战斗界面和菜单界面各有一个外观按钮，只要它们引用同一个模板，按任意一个都会继续轮替，不会各自从头开始。

切换布局模板后，外观轮替状态也会保留。应用重启后从原始组开始。

### 6.2 切换模板按钮：在不同操作方案之间切换

**作用**

临时切换当前布局模板。

**适合场景**

- 战斗布局和菜单布局切换；
- 步行和驾驶布局切换；
- 不同角色使用不同操作布局；
- 游戏中临时查看另一套控件。

**使用方式**

1. 在普通按钮的动作中选择“切换模板”；
2. 选择目标布局；
3. 可选：同时给这个按钮映射普通按键。

按下按钮时先触发映射按键，抬手后切换布局。切换后的布局会成为游戏内继续编辑的布局。

切换是临时的，不会修改游戏与默认布局的持久关联。

## 7. 外观和透明度

### 7.1 控件透明度

控制每个控件自身的透明度。

在全局外观中设置“控件透明度”时：

- 透明度不是 0% 或 100% 的控件会同步为新值；
- 已经是 0% 或 100% 的控件保持不变；
- 该值会成为新建控件的默认透明度。

这样设计是为了保留用户刻意设置的完全隐藏或完全不透明控件。

### 7.2 叠加透明度

叠加透明度是显示乘数，可以和控件透明度相乘。

- 范围 0–300%；
- 超过 100% 可以提亮低透明度控件；
- 不会直接修改控件自身透明度。

举例：

- 控件透明度 20%；
- 叠加透明度 200%；
- 实际显示约为 40%。

### 7.3 全局颜色

给当前布局所有控件统一上色，并作为新建控件的默认颜色。

适合：

- 统一界面风格；
- 提高按键在复杂背景上的可见度；
- 区分不同布局。

### 7.4 外观组

每个外观组可以单独设置颜色和叠加透明度，也都可以留空。

- 颜色留空：不覆盖颜色，继续使用每个控件自己的颜色；
- 叠加透明度留空：不覆盖模板叠加透明度。

原始组锁定，完全不覆盖控件外观，因此适合作为“默认显示”和“恢复原样”的组。

## 8. 编辑布局时的两种模式

### 从模板管理器编辑

没有游戏画面背景，所有控件以完全不透明方式显示，适合：

- 第一次搭建布局；
- 精确调整位置和大小；
- 编辑颜色和外观；
- 调整多屏幕配置。

### 在运行游戏中编辑

背景是游戏画面，控件使用真实透明度和外观，适合：

- 检查控件是否挡住重要 UI；
- 确认透明度是否合适；
- 确认按钮在游戏画面上的可读性。

## 9. 推荐的布局示例

### 动作游戏

- 左摇杆：移动；
- 右侧大划屏区域：视角；
- ABXY：普通按钮或组合按键；
- L/R、ZL/ZR：肩键和扳机；
- 一个 Turbo 按钮：连发；
- 一个外观按钮：隐藏/显示控件；
- 一个切换模板按钮：战斗/菜单布局切换。

### 格斗游戏

- ABXY 组合按键；
- 方向键组合；
- 手势区域：组合技；
- 少量大按钮：必杀、防御、投技；
- 外观按钮：隐藏不必要的 UI。

### 射击游戏

- 左摇杆：移动；
- 右侧划屏：瞄准；
- 开火按钮：R 或 ZR；
- 手势：换弹、蹲伏；
- Turbo：连射。

### 赛车游戏

- 左摇杆：转向；
- 划屏区域：观察周围；
- 大尺寸油门/刹车按钮；
- 切换模板按钮：比赛/菜单布局。

### 单手操作

- 隐藏摇杆区域；
- 手势区域承担组合操作；
- 外观按钮在需要时显示控件；
- 切换模板按钮进入简化菜单布局。

## 10. 导入、导出和备份

布局、划屏参数和外观参数都可以导出为 JSON。

导出布局时，会同时带上被引用的：

- 划屏参数；
- 外观参数。

导入时可以预览内容；相同 ID 的对象可以选择复制或替换。

建议：

- 大量修改布局前先导出备份；
- 分享布局时使用导出文件，而不是直接复制应用数据；
- 删除被引用的参数前先确认引用关系。

## 11. 常见问题

### 新建外观参数失败

请更新到最新版本。旧版本升级后需要先迁移旧显隐控件和旧外观组，最新版会自动保存迁移结果。

### 输入文字时布局会变化吗

当前版本在弹出输入法时会保持触控布局几何不变，只调整属性面板位置。

### 控件太亮或太暗

检查顺序：

1. 控件自身透明度；
2. 全局控件透明度；
3. 叠加透明度；
4. 当前外观组是否覆盖了颜色或叠加透明度。

### 外观按钮没有效果

检查：

- 外观模板是否至少有两个组；
- 当前组是否设置了颜色或叠加透明度；
- 外观按钮是否选择了正确模板。

### 切换布局后外观状态丢失

切换布局不会重置，但应用重启后会从原始组开始。

### 旧显隐按钮无效

显隐动作已移除。请用 0% 叠加透明度的外观组实现隐藏。
